# Лабораторна робота: Linked List (зв'язаний список)

Мова програмування: **C++17**. Усі 9 завдань реалізовані окремими функціями й доступні через консольне меню. Для зберігання вузлів використовується власна структура `ListNode` без `vector`.

## Завдання

1. **Об'єднати два відсортовані списки** — `mergeTwoLists()`. З'єднує вузли двох списків у неспадному порядку.
2. **Видалити дублікати** — `deleteDuplicates()`. Залишає по одному екземпляру кожного значення.
3. **Перевірити цикл** — `hasCycle()`. Використовує алгоритм двох вказівників (Floyd).
4. **Перевпорядкувати список** — `reorderList()`. Ділить список навпіл, розвертає другу частину та чергує вузли.
5. **Видалити вузол без доступу до голови** — `deleteNode()`. Копіює дані наступного вузла та вилучає наступний вузол; цільовий вузол не може бути останнім.
6. **Подвоїти число у списку** — `doubleIt()`. Розвертає список, подвоює цифри з перенесенням і повертає правильний порядок.
7. **Об'єднати k відсортованих списків** — `mergeKLists()`. Рекурсивно ділить масив списків навпіл і об'єднує частини.
8. **Розвернути вузли в k-групі** — `reverseKGroup()`. Розвертає повні групи, а неповну групу в кінці залишає без змін.
9. **Розділити список за x** — `partition()`. Стабільно ставить спочатку вузли зі значеннями меншими за `x`, потім решту.

## Як скомпілювати та запустити у VS Code

Потрібен компілятор `g++` (наприклад, MinGW-w64 на Windows). У терміналі з папки проєкту виконайте:

```powershell
g++ -std=c++17 main.cpp -o main.exe
.\main.exe
```

У меню введіть номер задачі від 1 до 9. Після виконання можна вибрати інше завдання або ввести `0` для завершення. Файл збережений у UTF-8; на Windows код встановлює UTF-8 для консолі.

## Приклади для перевірки

**1. Об'єднання двох списків** — обрати `1`:

```text
3
1 2 4
3
1 3 4
```

Очікувано: `[1, 1, 2, 3, 4, 4]`.

**2. Видалення дублікатів** — обрати `2`, ввести довжину `5` і список `1 1 2 3 3`.

Очікувано: `[1, 2, 3]`.

**3. Цикл** — обрати `3`, ввести довжину `4`, вузли `3 2 0 -4` та індекс `1`.

Очікувано: `Цикл є: true`.

**4. Перевпорядкування** — обрати `4`, ввести довжину `5` та список `1 2 3 4 5`.

Очікувано: `[1, 5, 2, 4, 3]`.

**5. Видалення вузла** — обрати `5`, ввести довжину `4`, список `4 5 1 9`, значення вузла `5`.

Очікувано: `[4, 1, 9]`.

**6. Подвоєння числа** — обрати `6`, ввести довжину `3` і цифри `9 9 9`.

Очікувано: `[1, 9, 9, 8]`.

**7. Об'єднання k списків** — обрати `7`, ввести `3`, потім довжини й елементи: `3` → `1 4 5`, `3` → `1 3 4`, `2` → `2 6`.

Очікувано: `[1, 1, 2, 3, 4, 4, 5, 6]`.

**8. Розворот k-груп** — обрати `8`, ввести довжину `5`, список `1 2 3 4 5`, `k = 2`.

Очікувано: `[2, 1, 4, 3, 5]`.

**9. Розділення списку** — обрати `9`, ввести довжину `6`, список `1 4 3 2 5 2`, `x = 3`.

Очікувано: `[1, 2, 2, 4, 3, 5]`.

## Складність алгоритмів

| № | Функція | Часова складність |
|---:|---|---|
| 1 | `mergeTwoLists` | O(n + m) |
| 2 | `deleteDuplicates` | O(n) |
| 3 | `hasCycle` | O(n) |
| 4 | `reorderList` | O(n) |
| 5 | `deleteNode` | O(1) |
| 6 | `doubleIt` | O(n) |
| 7 | `mergeKLists` | O(N log k) |
| 8 | `reverseKGroup` | O(n) |
| 9 | `partition` | O(n) |

Тут `n` і `m` — кількість вузлів у списках, `k` — кількість списків, `N` — загальна кількість вузлів.
